## Описание проекта
Объединенный проект лабораторных работ №1 и №2 по курсу "Спутниковые системы связи и навигации". Включает моделирование сигналов, спектральный анализ и цифровую фильтрацию.

## Функциональность
- Генерация синусоидальных сигналов с заданными параметрами
- Создание аддитивных и мультипликативных смесей с шумами
- Спектральный анализ с использованием FFT
- Частотная фильтрация сигналов
- Расчет и оценка отношения сигнал-шум (ОСШ)
- Сравнительный анализ различных типов шумов

## Параметры для бригады 1
- Длина массива: 50 отсчетов
- Типы шума: равномерный и нормальный
- Параметры шума: μ=0, σ=4
- Число синусоид: 2
- Амплитуды: [1, 3]
- Частоты: [3, 1] Гц
